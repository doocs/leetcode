## 加入我们

刷题最大的好处是锻炼「如何思考」。欢迎直接提 [PR](https://github.com/doocs/leetcode/pulls)。C# 题解由 [@kfstorm](https://github.com/kfstorm) 贡献。

1. Fork 本仓库到你的 GitHub 帐户，再 clone 到本地
2. 开新分支，按现有 `Solution.xxx` 和 README 模板补充题解
3. 提交后开 Pull Request，维护者会尽快 review
